# Power BI Sales Dashboard

## Sobre o projeto

Este projeto apresenta um dashboard interativo de análise de vendas desenvolvido com Microsoft Power BI. O objetivo é acompanhar indicadores comerciais e facilitar a análise do faturamento, dos custos e da lucratividade de uma loja fictícia.

## Objetivos

- Analisar o faturamento e o lucro das vendas.
- Acompanhar a quantidade de produtos vendidos.
- Calcular a margem de lucro.
- Comparar o faturamento ao longo dos meses.
- Explorar os resultados por categoria de produto e região.

## Tecnologias utilizadas

- **Microsoft Power BI Desktop:** criação do dashboard e das visualizações.
- **Power Query:** importação e transformação dos dados.
- **DAX:** criação das medidas e dos indicadores.
- **GitHub:** versionamento e documentação do projeto.

## Indicadores

- Faturamento total
- Custo total
- Lucro
- Margem de lucro
- Quantidade vendida

## Funcionalidades

- Cartões com indicadores comerciais.
- Gráfico de faturamento mensal.
- Filtros interativos por categoria e região.
- Análise dos resultados com base nas seleções realizadas.

## Como visualizar

1. Baixe o arquivo `.pbix` disponível neste repositório.
2. Abra-o no Microsoft Power BI Desktop.
3. Utilize os filtros de categoria e região para explorar os dados.

## Dados

O projeto utiliza dados fictícios criados para fins educacionais e de demonstração.
